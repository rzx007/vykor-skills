# 本仓库维护的技能

这里保存需要由市场直接分发的技能源码。每个技能目录包含 `SKILL.md`、适用许可证和运行所需的参考资料或示例。市场清单引用本仓库的固定提交，更新时先提交技能内容，再更新清单中的提交和版本。

- [develop-nomi-app](develop-nomi-app/SKILL.md) 用于创建 Nomi Web 应用或把已有网页接入 Nomi 桌面。配套参考文档和最小项目保留在同一技能目录。当前快照同步自 Nomi GitLab 主线提交 `1471c7ea2743b63be953b9b56730df14a0a2f0c3`，使用 SDK `0.3.0`，按 MIT 许可分发。分发副本将 README 中的源码仓库内部链接改为文字说明。
- [create-plugin](create-plugin/SKILL.md) 用于开发、验证和打包 Vykor 插件，包含 Native Tools 与 MCP 两种后台的天气工程及文本检查示例。首次收录来自 Vykor 提交 `afaddade7a3ca0a7f32f2a3d8b8a223f8c934935`，按 MIT 许可分发。市场副本将天气 Skill 存为模板文件，生成工程时恢复其入口名称。
- [agent-reach](agent-reach/SKILL.md) 用于跨平台搜索和只读阅读。同步自官方 `v1.6.1` 提交 `7a38047acf26a729cbb27851e3cb81639da86b29`，用该版本的生成器展开中文技能，按上游 MIT 许可分发。市场副本补充首次使用、安装范围和固定版本的初始化说明。
- [heritage-blueprint](heritage-blueprint/SKILL.md) 用于制作古建蓝图。保留 MIT 代码、模板和 OFL 字体，按上游 COPYRIGHT 声明通过链接查阅保留版权的展示成品；固定来源与改动见该目录 README。
- [blender](blender/SKILL.md) 按任务加载 Blender 仓库的 94 份指南，并保留其共享参考资料与 MIT 许可证。
- [answer-me-with-html](answer-me-with-html/SKILL.md) 生成图文 HTML，保留上游单文件程序和字体许可，并补齐该构建所引用的第三方通知。
- [archify-pr](archify-pr/SKILL.md) 为变更生成图解，依赖独立的 archify 核心技能；保留上游 Apache、历史 MIT 及 NOTICE 声明。
- [ponytail-gain](ponytail-gain/SKILL.md) 保留上游基准说明，将来源改为固定提交链接。
- [ponytail-help](ponytail-help/SKILL.md) 保留六个技能和级别说明，安装、调用与更新方式适配 Vykor 技能市场。
