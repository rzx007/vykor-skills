# Agent Reach 技能

本目录按 MIT 许可分发官方 Agent Reach `1.6.1` 中文技能和参考资料。上游为 `Panniantong/Agent-Reach` 的固定提交 `7a38047acf26a729cbb27851e3cb81639da86b29`。

`SKILL.md` 由该版本自带的 `render_skill("zh")` 生成，展开版本号和渠道表。市场副本增加首次使用和安装范围说明，并附带固定到官方 `v1.6.1` 下载地址的安装文档。使用入口为 `SKILL.md`，初始化、能力边界、登录及维护说明位于 `references/`。

运行环境需要 Python 3.10+；按安装文档用 uv 准备命令行程序。各渠道的工具、浏览器和账号由 Agent Reach 管理。个人和项目安装范围控制技能可见性。
